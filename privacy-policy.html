Vulpedit PDF Page Editor 隱私政策

適用版本：Chrome 0.1.6。發布者：FloofyFox；聯絡信箱：floofyfox03@gmail.com；生效日期：2026-11-06。

文件只在您的裝置處理

您選擇或拖入的 PDF、圖片、DOCX、檔名，以及您主動貼上的文字、表格、圖片，僅用於本機匯入、預覽、編輯及匯出。擴充功能不將這些內容上傳給開發者或第三方，不出售或分享文件資料。沒有開發者伺服器、帳號登入、廣告、遙測或分析追蹤服務。

剪貼簿與權限

使用貼上按鈕時，可能要求選用的 clipboardRead 權限，以讀取您要加入文件的內容。授權後，程式也只在您操作貼上功能時讀取，不定時或背景監看剪貼簿。可以拒絕並改用鍵盤貼上；可在 Chrome 的擴充功能設定撤銷權限。不要求一般網站存取權限或瀏覽紀錄權限。

保存與刪除

語言、佈景及面板寬度偏好儲存在本機瀏覽器儲存空間。編輯工作只在目前工作階段中使用，沒有自動儲存或雲端同步；關閉編輯器會失去未匯出的工作。這不構成對作業系統記憶體或快取安全抹除的承諾。匯出的 PDF 或 ZIP 由您保存於本機，須自行刪除。移除擴充功能可移除其本機設定；先前下載的文件不會因此刪除。

網路與外部服務

安裝完成後，第一次啟動及文件處理不需網路，也不會下載執行依賴。Chrome 商店安裝與瀏覽器更新機制屬瀏覽器自己的服務。若您主動點擊 About 中的 GitHub 連結，會開啟外部網站，該網站適用自己的隱私政策。目前沒有贊助收款連結或金流 SDK。未來如新增贊助，會先更新本政策並說明外部服務。

政策網站的託管

本政策頁由 GitHub Pages 提供。瀏覽本頁時，GitHub 會為安全目的記錄及保存訪客 IP 位址；這與擴充功能在本機處理 PDF 是不同的流程。本頁不加入廣告、分析追蹤程式、第三方字型或付款元件。詳見 GitHub 隱私聲明。客服信箱使用 Gmail，詳見 Google 隱私權政策。

聯絡與政策變更

若您主動透過發布者提供的支援信箱聯絡，您寄出的信件由您使用的郵件服務傳送；請勿附上不必要的敏感文件。支援信件由 FloofyFox 本人透過上述 Gmail 信箱接收及處理，僅用於回覆您的問題。信件中的聯絡資料、內容及附件在案件結束後最長保存 12 個月，再由發布者刪除；法律要求保存或尚有爭議需處理者除外。您可透過同一信箱提出刪除要求。Gmail 服務本身的資料處理與備份依 Google 的政策運作，發布者刪除郵件不代表服務商所有備份立即清除。本政策有變更時會更新本頁日期；涉及資料處理變更時也會更新商店揭露。

Vulpedit PDF Page Editor Privacy Policy

For Chrome version 0.1.6. Publisher: FloofyFox. Contact email: floofyfox03@gmail.com. Effective date: November 6, 2026.

Local document processing

PDFs, images, DOCX files, filenames, and text, tables or images you explicitly paste are used locally to import, preview, edit and export documents. The extension does not upload these contents to the developer or third parties, sell them or share them. It has no developer backend, account login, advertisements, telemetry or analytics service.

Clipboard and permissions

The paste button may request the optional clipboardRead permission. Even after permission is granted, the application only reads the clipboard when you invoke paste; it does not monitor the clipboard in the background. You can decline and use keyboard paste instead, and revoke permission in Chrome extension settings. No general website access or browsing history permission is requested.

Retention and removal

Language, theme and panel width preferences are stored locally in the browser. Editing state is used in the current session, without autosave or cloud synchronization. Closing the editor loses unexported work. This is not a guarantee of secure erasure from operating-system memory or caches. Exported PDFs and ZIPs are saved by you and must be deleted by you. Removing the extension removes its local settings; previously downloaded documents remain.

Network and external services

After installation, first launch and document processing work without a network connection or dependency downloads. Store installation and browser updates are separate browser services. Clicking the GitHub link in About opens an external site governed by its own policy. This version has no sponsorship payment link or payment SDK. A future sponsorship integration will require an updated policy and service disclosure.

Policy website hosting

This policy page is hosted by GitHub Pages. When you visit it, GitHub logs and stores visitor IP addresses for security purposes. This is separate from local PDF processing in the extension. This page includes no advertising, analytics scripts, third-party fonts or payment components. See the GitHub Privacy Statement. The support mailbox uses Gmail; see the Google Privacy Policy.

Contact and updates

If you voluntarily email the publisher for support, your email provider transmits your message. Please avoid unnecessary sensitive attachments. FloofyFox personally receives and handles support messages through the Gmail address above, solely to answer your questions. Contact details, message contents and attachments are retained for no more than 12 months after a case is closed and are then deleted by the publisher, unless retention is legally required or necessary for an unresolved dispute. You may request deletion through the same email address. Gmail processing and backups are governed by Google policies; publisher deletion does not mean all provider backups are immediately erased. Policy changes will be dated here; changes to data handling will also be reflected in store disclosures.
